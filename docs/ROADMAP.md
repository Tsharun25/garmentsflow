# Current roadmap

Use PRODUCT_BRIEF.md and PROGRESS.md for the owner-approved 2026-11-13 plan; the old MongoDB phase numbering is superseded.

0. Discovery: provisional Woven/Knit maps, ERD, posting rules and permission matrix. Validate forms, tolerances, approval owners and correction paths with the pilot.
1. Foundation: PostgreSQL/RLS, identity, Main Admin, scoped roles, audit, Docker and CI. First account/factory-note slice is implemented; MFA/invitations and operational evidence remain pending.
2. PO to stock issue: approved PO/BOM revisions, planning/material readiness, Store receipt/reservation/issue/return/transfer and Excel import. Require reconciliation, concurrency, idempotency and rollback tests.
3. Stock issue to shipment: Cutting/Sewing/Quality/Finishing/Packing/Commercial, traceability, partial shipments, amendments and finalized document corrections.
4. Operational pilot: Woven/Knit staff UAT, licensed and SaaS deployment/upgrade/restore rehearsals, measured load and acceptance.

Marketplace submission follows demonstrated scope, clean setup, demo, documentation, deployment routes, media and marketplace audit/review. Local checks do not prove acceptance or sales.
